============================================================
PRICING — UAE DIRHAM
============================================================

IMPORTANT:

All FansConnect subscription plans must be priced in:

AED — United Arab Emirates Dirham

Do NOT use:

SAR
USD
ريال
$ 

The default platform currency is:

AED

Display prices using:

AED

Examples:

149 AED / month
349 AED / month
699 AED / month

Arabic display:

149 درهم / شهرياً
349 درهم / شهرياً
699 درهم / شهرياً

English display:

AED 149 / month
AED 349 / month
AED 699 / month

============================================================
PLAN CONFIGURATION
============================================================

Do not hard-code prices directly inside React components.

Prices must come from backend/database plan configuration.

Each Plan should have:

name
description
price
currency
billingInterval
limits
features
isPopular
isActive

Example:

currency:
"AED"

billingInterval:
"MONTHLY"

============================================================
ZIINA
============================================================

Ziina is the payment provider.

All subscription checkout amounts must be sent using AED.

Before creating checkout:

- validate plan.currency === "AED"
- validate amount
- send correct AED amount to Ziina
- never convert AED to SAR automatically

============================================================
CURRENCY FORMATTING
============================================================

Use Intl.NumberFormat.

Arabic:

new Intl.NumberFormat("ar-AE", {
  style: "currency",
  currency: "AED"
})

English:

new Intl.NumberFormat("en-AE", {
  style: "currency",
  currency: "AED"
})

Do not manually concatenate currency symbols where Intl formatting is appropriate.
