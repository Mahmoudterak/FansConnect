The current Channels page exposes this message to customers:

"Meta provider setup is required. Add META_APP_ID, META_APP_SECRET,
and META_REDIRECT_URI to start authorization."

META_APP_ID
META_APP_SECRET
META_REDIRECT_URI

============================================================
3. OAUTH ARCHITECTURE
============================================================

The Meta OAuth configuration belongs to FansConnect server-side.

Customer flow:

Customer clicks:

"ربط WhatsApp"

↓

Frontend calls backend connection endpoint

↓

Backend starts Meta OAuth using:

META_APP_ID
META_APP_SECRET
META_REDIRECT_URI

↓

Customer is redirected to Meta

↓

Customer authorizes FansConnect

↓

Meta redirects back to backend

↓

Backend validates callback

↓

Backend stores only the required customer/channel credentials
securely and encrypted where applicable

↓

Backend verifies the WhatsApp Business connection

↓

Channel becomes:

CONNECTED

ONLY after successful verification.

5. SETUP MISSING STATE
============================================================

There is an important distinction.

If the PLATFORM administrator has not configured Meta:

The customer should NOT see:

"Add META_APP_ID..."

Instead the customer sees a generic state such as:

"تعذر بدء ربط WhatsApp حالياً."

"يرجى المحاولة لاحقاً."

The detailed configuration problem should appear ONLY in:

Super Admin
or
server logs

Example internal admin error:

META provider configuration is incomplete.

The customer must never see environment variable names.
